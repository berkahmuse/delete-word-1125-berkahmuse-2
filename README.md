## The word

**shenanigans**

One word, erased from the dictionary forever. Delete it and the language
loses its favourite name for mischief: no more shenanigans, ever, because
nobody can call them that anymore.

## How it works

`main.ts` (Node 22, no dependencies) writes the single word to
`/output/entry.txt`:

```sh
node main.ts
```

The entry is 11 characters of plain UTF-8 text, inside the gate's 1–77
character window.
